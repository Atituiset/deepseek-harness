# 前言与使用指南

这是一套以 **deepseek-harness 仓库本身为教材** 的 Agent 开发教程。deepseek-harness 是一个基于插件化框架 Cordis 构建的 Agent Harness（智能体运行骨架）——在它的设计里，**一切皆插件**：LLM 接入、工具、权限、持久化、甚至 Agent 循环本身，都是挂在同一棵插件树上的可替换部件。学会读这个仓库，你就掌握了构建一个生产级编码 Agent 所需要的全部核心机制。

## 你会学到什么

- **入门篇（第 1–7 章）**：跑通一个真实 Agent，读懂它的配置，然后亲手给它加工具、加插件、换组合。学完你能用这套框架搭出符合自己需求的 Agent。
- **进阶篇（第 8–15 章）**：精读 Agent Loop、事件溯源 Session、工具执行管线等核心源码，理解「能力接缝」这一贯穿全仓库的设计模式，最终能自己写 LLM 适配器、子代理 Provider，并用项目的测试体系验证改动。

## 前置要求

- 能读写 TypeScript（不需要精通，能看懂类、接口、async/await 即可）。
- Node.js `^22.19 || >=24` 与 pnpm 11（仅动手章节需要）。
- 一个 DeepSeek API Key（`DEEPSEEK_API_KEY`）。没有 Key 也能学：第 3 章的框架教程和第 2 章的快照回放都不需要联网调用模型。

## 建议的学习路线

```text
入门篇  跑起来(1-2) → 懂框架(3) → 懂配置(4) → 加工具(5) → 加插件(6) → 自由组合(7)
进阶篇  架构图(8) → Loop 源码(9) → Session(10) → 接缝模式(11) → 工具管线(12)
       → 写适配器(13) → 子代理(14) → 测试(15)
```

两条线可以穿插：入门篇每章末尾都标了对应的进阶章节，想深挖时随时跳过去。

## 怎么读这本书

- 每章结构统一：**目标 → 概念讲解 → 动手练习 → 延伸阅读**。
- 书中所有引用都给出仓库内的**精确文件路径**（常带行号），请务必打开源码对照着读——这本书是地图，源码才是领土。
- 所有路径相对于仓库根目录。行号会随仓库演进漂移，差几行属正常，按符号名搜索即可。
